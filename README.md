#  Airport Management System

##  Description
This is a Java Swing-based desktop application developed to manage airport passenger records. The system allows users to perform operations like adding, updating, deleting, and viewing passenger details using a MySQL database.

## 🚀 Features
- User Login System
- Add Passenger Details
- Update Passenger Records
- Delete Passenger Records
- View Passenger Data in Table
- Check-in Status Management

## 🛠️ Technologies Used
- Java (Swing)
- MySQL
- JDBC

## 🗄️ Database
- Database Name: airport_db
- Table Name: passengers

## ▶️ How to Run
1. Open the project in NetBeans
2. Start MySQL server
3. Create database `airport_db`
4. Run the project
